# Percentage Bereken Tool

Een moderne, responsive percentage calculator met Bootstrap design en JavaScript functionaliteit.

## Functionaliteiten

### 1. Neem een percentage van een getal
- **Wat is X% van Y?**
- Voorbeeld: Wat is 10% van €2000? = €200

### 2. Welk percentage is een getal?
- **X is welk procent van Y?**
- Voorbeeld: €50 is welk procent van €1000? = 5%

### 3. Verhoging / Verlaging
- **De waarde X plus/min Y% = ?**
- Voorbeeld: €2000 plus 10% = €2200

### 4. Percentage verschil
- **Het verschil tussen X en Y = welk percentage?**
- Voorbeeld: Van €1000 naar €1200 = +20% stijging

- ✅ **Responsive Design** - Werkt op alle apparaten

## Gebruik

1. Open `index.html` in een webbrowser
2. Vul de gewenste waarden in
3. Klik op "Berekenen" of druk op Enter
4. Bekijk het resultaat met uitleg

## Formules

### Percentage berekenen
```
percentage = (deelbedrag / geheelbedrag) × 100
```

### Percentage verschil
```
verschil (%) = ((nieuw - oud) / oud) × 100
```

### Verhoging/Verlaging
```
nieuw bedrag = oud bedrag ± (percentage / 100) × oud bedrag
```
